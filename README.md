# Kimi CLI Notes

Kimi CLI is not a community wrapper: Moonshot AI ships it as one of three official surfaces for Kimi Code, alongside the desktop app and the IDE plugins.

**Read the full page:** https://kimi-cli.github.io/

This is worth installing if you work in a terminal all day and want an agent that reads your codebase, edits files and then runs the tests to check its own work, on the same subscription that covers the desktop app and the IDE plugins. It is not for anyone who wants an offline or free-standing tool, because the agent is tied to a Kimi membership and the strongest model is gated to higher tiers. The caveat worth repeating: an agent with permission to execute commands is a security decision, not just a productivity one. If you only want a site or app generated and handed over, Begin.sh does that without anything touching your shell.
